# eBay無在庫 利益計算機

eBay(US)への無在庫出品を想定した利益計算UI。計算ロジックは `src/core/ebay-calculator.ts` の
`calculateEbayProfit` / `calculateBreakEvenSalePriceUsd` に純粋関数として切り出してあり、このコンポーネントは
入力フォームと結果表示のみを担当する。

## 計算の考え方

- 利益率は「利益 ÷ 販売価格（送料込み売上合計）× 100」の粗利率。仕入れ値に対するROIとは別に算出し、
  `roiPercent` として画面下部にも表示している。
- per-order fee は eBayの実際の手数料体系に合わせ、取引合計（`totalSaleUsd`）が $10 以下なら $0.30、
  超えるなら $0.40。ただし `totalSaleUsd` が 0 のときは 0 として扱う。
- 国際送料・FVFカテゴリはプリセットのセレクトから選ぶと下の数値欄に反映される。数値欄を直接編集すると
  自動的に「手動入力」扱いになる。
- 関税（DDP）は米国の de minimis 撤廃（2025/8/29）を踏まえ、通常は買い手負担（DDU）で売上に影響しない前提。
  自分で負担する場合だけトグルをONにする。デフォルトの関税率15%は日米合意のベースライン関税で、実際の税率は
  品目により異なる。
- 「目標利益率にするための販売価格」は二分探索（0〜$100,000、1セント精度）で算出している。

## スタイル

`../procurement-calculator/styles.css` の `.calculator` 系クラスをベースに、内訳リストやトグルスイッチなど
このコンポーネント固有のスタイルのみ `./styles.css` に追加している。新しいCSSフレームワークは使用していない。
